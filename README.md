# DAO V1

DAO V1 is an operating scaffold for a small, accountable, automation-assisted organization. It separates policy from execution and keeps durable records in version control.

## Repository map

```
docs/        durable operating documentation and decisions
plans/       delivery and improvement plans
sessions/    session templates and completed records
teams/       charters and responsibility maps
contracts/   machine-readable integration definitions
schedules/   human and automation cadence specifications
skills/      reusable playbooks (placeholder for V1)
```

No live automation credentials or mailbox data belong here. Configure them in the target secret manager and n8n instance.
