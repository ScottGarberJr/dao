# DevTeam discovery handoff

- Team: DevTeam
- Status: draft — pending user review

## Objective

Perform project discovery and prepare its design handoff. This is a DevTeam task that may be carried out by a dedicated discovery agent.

## Inputs

- A client or personal project brief, available project context, and the user's stated goals.
- Access to appropriate research sources and a Figma file for the resulting reference pages.

## Workflow

1. Collect client and competitor information, relevant industry or niche context, winning web-design practices, and linked or screenshot references.
2. Create the discovery and reference pages in the Figma file; for client work, use them to drive the client discussion before planning or building.
3. Confirm the discovery is complete enough to inform a design direction; request clarification from the user when it is not.
4. Link the relevant Figma pages in the project-specific documentation and hand them, with project constraints, to `DESIGN.md`.

## Tools, skills, and references

[Figma MCP](https://developers.figma.com/docs/figma-mcp-server/) is the candidate interface for reading the handoff pages. It is not connected or approved for use.

## Scope, permissions, and constraints

Do not publish or modify client-facing material without the user's authorization. Use ResearchTeam only when a defined Research capability is specifically needed beyond this DevTeam discovery task.
