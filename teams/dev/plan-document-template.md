# Project version or patch plan template

Create version and patch plans in `project/plans/` after the user has approved planning. Name a version `v<major>.0.md` (for example, `v1.0.md`) and its patches `v<major>.<patch>.md` (for example, `v1.1.md`). Use numbered work sections in `major.patch.item` form: `1.0.1`, `1.0.2`, and `1.1.1`.

For Version 1.0, begin with **1.0.1 — Project scaffolding and boilerplate**. It captures the common project foundation required before product features, adjusted to the project’s actual needs.
