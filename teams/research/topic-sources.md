# Research topic sources

## DAO, Codex, skills, and Sites

- Official OpenAI documentation and product documentation first.
- The relevant repository's current `project/` documentation and `AGENTS.md` where present.

## GitHub repositories, MCPs, tools, and APIs

- Official upstream repository and maintainer documentation first.
- Official MCP registry or provider documentation second.
- Community discussion only as supplemental evidence, clearly labeled as such.

## Design

- Current project design documentation and agreed design system first.
- Official Figma documentation and files when available.
- Refero Styles and other real-product references as supporting inspiration, not copied requirements.

## SEO and owned-site performance

- Google Search Console data and documentation first for owned properties.
- Official provider documentation for approved SEO data tools.
