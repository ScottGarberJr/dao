# Morning standup report template

Use this as the structure for the daily report. Replace placeholders with verified runtime data and omit empty sections only when the source returned no relevant items.

```markdown
[Greeting in another language] ([rough English translation])

Weather — [location]
- Morning: [temperature and conditions in °F]
- Afternoon: [temperature and conditions in °F]

Calendar today
- [Unique event, time, and organizer/source note]
- [Routine events omitted by the calendar pass list]

Reminders
- Today: [all-day reminders and TODO descriptions]
- Tomorrow: [all-day reminders and TODO descriptions]
- Next day: [all-day reminders and TODO descriptions]

Email

Gmail
- [Sender] — [Subject] — [why it matters or short summary]

SG Solutions
- [Sender] — [Subject] — [why it matters or short summary]

Scott Outlook
- [Sender] — [Subject] — [why it matters or short summary]

That's all, [salutation conveying “Have a good day!”]
```

## Artifact naming

Save the complete report under:

`Documents/Vaults/AGENTS/gu/standups/M.DD.YYYY - Weekday.md`

The report may include a short source note at the bottom if a provider failed or returned incomplete metadata. Do not include credentials, raw message bodies, or unnecessary provider identifiers.
