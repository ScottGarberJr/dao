# DAO plans

Plans describe what will be built, rather than serving as the permanent definition of the project. Version plans use `v<major>.0.md` (for example, `v1.0.md`); patches use `v<major>.<patch>.md` (for example, `v1.1.md`). Their numbered work sections use the third tier: `major.patch.item` (for example, `1.0.1` and `1.1.1`). Each section has a name, one-line summary, task checklist, and acceptance-criteria checklist. Update a plan when scope, dependencies, or completion state changes.
