# UI UX Pro Max

## Purpose

Choose a deliberate visual direction before UI implementation by matching product category, audience, typography, color, layout, and density. This skill is guidance for a design decision; it does not authorize installing or calling an external engine.

## Use when

- a project needs a stronger visual point of view;
- a landing page or product category needs a tailored design system;
- the agent is drifting toward generic defaults.

## Procedure

1. Read the design brief, direction lock, constraints, and approved references.
2. Identify the product category, audience, trust posture, content density, and platform.
3. Propose a small set of category-fit directions with rationale and anti-patterns.
4. Record the selected direction in `project/docs/design.md` and the design system.
5. Use the direction during UI Creation and verify it during Design Review.

## Boundaries

Do not copy a proprietary product, treat a generated recommendation as user approval, or add an external dependency without project-level authorization.

## Verification

The selected direction is explicit, explainable, distinct from rejected alternatives, and visible in the review evidence.
