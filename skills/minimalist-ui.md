# Minimalist UI

## Purpose

Use restraint, whitespace, hierarchy, readable typography, and limited visual noise for an approved minimalist direction.

## Procedure

1. Confirm minimalist direction in the direction lock.
2. Prefer a small type scale, clear hierarchy, generous spacing, and purposeful emphasis.
3. Remove decoration that does not improve comprehension or action.
4. Check that simplicity does not hide states, affordances, or accessibility cues.
5. Run Design Review before polish.

## Boundaries

Do not use minimalism to omit required information, states, contrast, focus treatment, or responsive behavior.
