# Mobile UI Principles

## Purpose

Design mobile as a touch-first platform with reachable controls, clear hierarchy, bounded type scales, safe-area awareness, and platform-appropriate behavior.

## Procedure

1. Identify the platform, device classes, hand/reach assumptions, primary tasks, and offline or network states.
2. Keep primary actions in reachable thumb zones and make touch targets clear and forgiving.
3. Use a limited, consistent type scale, predictable navigation, safe areas, keyboard handling, and complete loading/empty/error states.
4. Check responsive behavior, orientation, accessibility, dynamic text, reduced motion, and platform conventions.
5. Use Material 3, SwiftUI, or Expo guidance when the project stack calls for it.
6. Run Design Review before visual polish.

## Boundaries

Do not treat mobile as a compressed desktop page or assume iOS and Android behavior are interchangeable.
