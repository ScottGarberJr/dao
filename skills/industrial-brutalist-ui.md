# Industrial Brutalist UI

## Purpose

Provide a deliberate raw, structural, high-contrast visual direction without sacrificing usability, accessibility, or product clarity.

## Procedure

1. Confirm the direction, audience, and acceptable level of visual provocation.
2. Use strong hierarchy, structural grids, direct language, deliberate contrast, and restrained ornament.
3. Test legibility, focus states, responsive behavior, and motion before calling the style complete.
4. Run Design Review to distinguish intentional brutality from clutter or unfinished work.

## Boundaries

Do not apply this preset by default, use illegible typography, or treat anti-corporate styling as permission to weaken accessibility.
